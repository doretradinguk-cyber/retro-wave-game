# Retro Wave Game — Godot 4

Neon Hollow, a first-person retrowave horror game for Windows and mobile. All active game scenes, GDScript, shaders and resources are developed in this repository.

## Open the foundation

In the standard Godot 4.4+ editor, choose **Import** and select this repository's `project.godot`, then edit the project. The current main scene is a foundation notice. Player movement, corridor geometry and gameplay are the next development phase.

See [Godot project structure](docs/GODOT-STRUCTURE.md), [master handover](README-MASTER-HANDOVER.md) and [asset pipeline](docs/ASSET-PIPELINE.md).

Raw/editable assets live in `doretradinguk-cyber/the-drop-zone/retro-game-assets`. The separate `seumas-lewis-dashboard` links to test builds; it does not contain the Godot runtime.
